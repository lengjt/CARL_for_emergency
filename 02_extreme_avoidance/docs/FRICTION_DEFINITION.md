# 附着能力研究定义

## 1. 主变量

在线规划实验的主附着变量改为 `lambda_peak(x,y,t)`，场景显式选择 `friction_mode: internal_mu`。`base_scale` 和 `patches[].scale` 在此模式表示内部峰值参数的倍率。每个物理步在四个轮胎接地点分别查询该变量。

原生绑定以冻结参数为基准更新各轮：

```text
LMUX_i = baseline_LMUX_i * lambda_peak_i
LMUY_i = baseline_LMUY_i * lambda_peak_i
ExternalInfluences.lambda_mue_i = 1
```

基准值在模型 reset 时从配置读取，倍率不会逐步累乘。外部倍率为 1，避免重复折减。旧场景未声明模式时仍为 `post_force`：`Fx=lambda_F*Fx_MF52, Fy=lambda_F*Fy_MF52`。两种倍率都不是已辨识的路面绝对 μ。

控制器通过 `capability_scale_estimate` 获取可带偏差与延迟的真值代理。新规划器采用当前四轮估计的最小值并在预测时域内保持，不能看到未来分区或未揭示障碍；旧反馈基线仍不使用该估计。`force_scale_estimate` 和 `scale_estimate` 是历史兼容别名，含义必须结合 `friction_mode` 判断。

## 2. 派生报告量

为了让倍率具有可读的物理量级，报告在参考轮荷 2500 N、零外倾和固定扫描范围内分别求得的峰值 `max|Fx|/Fz` 与 `max|Fy|/Fz`。冻结轮胎在 `lambda_F=1` 时，两者约为 1.461 和 1.179；后置缩放使它们分别按 `lambda_F` 线性变化。两个纯滑移峰值不能同时使用，也不构成一个全局路面 μ。

参考轮荷、扫描范围和声明边界由 [配置文件](../configs/friction_definition.json) 固定。运行 `scripts/calibrate_friction.py` 可重建标定表，并同时比较后置力缩放与内部 `LMUX/LMUY` 缩放。

在 2026-10-15 的有限网格对照中，`lambda_F=0.5` 时两种方法得到近似相同的纯滑移峰值，但曲线并不相同：

| 方法 | 小滑移纵向刚度 | 纵向峰值滑移率 | 小滑移横向刚度 | 横向峰值侧偏角 |
|---|---:|---:|---:|---:|
| 后置力缩放 | 37473 N | 0.220 | 39300 N/rad | 0.112 rad |
| 内部 `LMUX/LMUY` 缩放 | 74798 N | 0.110 | 78434 N/rad | 0.057 rad |

这说明两种方法只能在指定峰值指标上对齐，不能互换。原始数值保存在 `artifacts/friction_calibration_20261015.json`。

## 3. 主模型选择和校验

内部峰值缩放将峰值能力与初始刚度区分开，适合当前“附着峰值下降”的研究假设；它也已支持逐轮时空查询。代码回归将运行时内部缩放与直接修改冻结参数的车辆逐状态比较，检验无重复缩放和无倍率累乘。物理检查见 `artifacts/planning_validation_v3/report.json`。

内部缩放并不证明初始刚度在所有真实路面都不变。温度、压力、迟滞等仍未辨识，本阶段结论应限定于冻结轮胎模型的峰值能力变化。共用制动滑移调节阈值仍为 0.10/0.18；已检查当前倍率档位的停车与联合操纵，但没有宣称其在所有轮荷下保持最佳滑移。

## 4. 敏感性与后续升级

敏感性对照使用旧 `post_force` 模式及附着估计的 0.8/1.2 倍率偏差。若模型选择改变方法的相对结论，应把附着建模列为主要不确定性。单个对照工况不能证明跨模型泛化。

当课题需要对具体湿地或冰雪路面作结论时，应使用相应轮胎—路面数据重新辨识参数集；不能只把倍率改名为 μ。
